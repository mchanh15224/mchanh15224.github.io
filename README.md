# Chanh — GitHub Pages Portfolio

Portfolio cá nhân phong cách Apple-inspired, xây dựng bằng HTML, CSS và JavaScript thuần.

## Cấu trúc

```text
.
├── index.html
├── style.css
├── script.js
├── README.md
└── .nojekyll
```

## Chạy thử trên máy

Mở `index.html` bằng trình duyệt. Không cần cài framework hoặc build tool.

## Deploy lên GitHub Pages

1. Tạo repository tên **`mchanh15224.github.io`** (thay username nếu khác).
2. Upload toàn bộ nội dung thư mục này lên nhánh `main`, đặt `index.html` ở thư mục gốc.
3. Vào **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/ (root)`, nhấn **Save**.
6. Đợi GitHub Actions deploy xong, website sẽ ở `https://mchanh15224.github.io`.

## Việc cần cá nhân hóa trước khi public

- Trong `index.html`, thay `YOUR_EMAIL@example.com` bằng email liên hệ thật.
- Kiểm tra username GitHub và các đường dẫn repository.
- Bổ sung link repo/demo, ảnh chụp màn hình và mô tả dự án khi đã sẵn sàng công khai.
- Điều chỉnh phần giới thiệu, kỹ năng và hành trình theo kinh nghiệm thực tế của bạn.

## Công nghệ

- HTML5 semantic
- CSS responsive, không dùng framework
- Vanilla JavaScript
- Google Fonts (Inter); nếu muốn website không phụ thuộc dịch vụ ngoài, có thể bỏ dòng Google Fonts trong `index.html` và `style.css`.
